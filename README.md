# Sistema de Inventario - PYTHON_DATA_ANALITIC_APRENDIZAJE

Este proyecto es parte de mi aprendizaje autodidacta en Python y análisis de datos. Consiste en un sistema de inventario con funcionalidades básicas de gestión de productos, validaciones y pruebas.

## Estado actual (versión inicial)

Actualmente el sistema cuenta con las siguientes características:

- **Clase `Inventario`** que gestiona una lista de productos (diccionarios con nombre, precio y stock).
- **Agregar productos** con validación de precio mínimo ($1).
- **Eliminar productos** por nombre.
- **Buscar productos** por coincidencia parcial en el nombre.
- **Aplicar descuentos** a un producto específico (porcentaje).
- **Mostrar inventario** con formato tabular y emojis.
- **Pruebas integradas** que demuestran el funcionamiento (incluidas en `inventario.py`).

Los archivos actuales son:

- `inventario.py` – Contiene la clase `Inventario` y un bloque de pruebas que se ejecuta al correr el script.
- `ventas.py` – (pendiente de desarrollo/definición)
